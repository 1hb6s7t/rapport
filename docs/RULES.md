# 规则模式到底在算什么

> 读者：想知道"这个分怎么来的"的人。这里写的全部是**产品假设**——锚点、权重、词表没有经过任何校准。分数描述的是聊天里**可观察的互动行为**，不是对方心里有多喜欢你。

## 输入

解析后的每条消息：谁发的、什么时候、什么类型（文本 / 图片 / 语音…）、文本内容。规则模式不调用任何模型，不出网。

## 第一步：特征（`features/compute.py`）

1. **切会话**：两条消息间隔 ≥6 小时就算新的一段会话。
2. **每一方各算一遍**：消息数、文本数、字符数、平均与中位长度、媒体数；以及下面这些**词表命中率**（命中条数 ÷ 文本条数）：

| 词表 | 例子 | 用在哪 |
|---|---|---|
| 提问 `QUESTION_RE` | ？/ 吗 / 怎么 / 几点 / 要不要 | 主动性 |
| 笑 `LAUGH_RE` | 哈哈 / 233 / 😂 / 笑死 | 情感温度 |
| 关心 `CARE_RE` | 早点休息 / 吃了吗 / 路上小心 / 辛苦了 | 情感温度、阶段 |
| 亲昵 `AFFECTION_RE` | 想你 / 宝贝 / 抱抱 / 😘 | 情感温度、阶段 |
| 未来 `FUTURE_RE` | 下次 / 周末 / 一起 / 见面 | 未来指向（兜底）、阶段 |
| 短回复 `SHORT_REPLY_RE` | 嗯 / 哦 / 好的 / 收到 | 投入度（反向） |

3. **时间类**：对方中位回复延迟、5 分钟内回复率、24 小时内回复率、每段会话由谁开启、连发率（一口气发 ≥2 条）、深夜率。
4. **邀约链**（`features/invitations.py`）：我提议（`PROPOSE_RE`：要不要一起 / 有空吗 / 看电影）→ 对方在 6 条内的回应：答应（`ACCEPT_RE`：好啊 / 几点 / 在哪）、改期（`ALT_TIME_RE`：改天 / 下次）、拒绝（`DECLINE_RE`：不去了 / 没空）、绕开、没回 → 之后是否落定具体时间（`COMMIT_RE`：周六 / 三点 / 明晚）。

## 第二步：五维打分（`scoring/rubric.py`）

每个指标先经**锚点表**分段线性映射到 0–100，再按固定权重加权。缺失的指标不补 0，按可用权重归一。

| 维度（总分权重） | 指标（维内权重） | 锚点例子（指标值 → 分） |
|---|---|---|
| 回应性 0.25 | 中位回复延迟 0.5 · 5 分钟内回复率 0.25 · 24h 回复率 0.25 | 1 分钟→95，15 分钟→72，1 小时→58，4 小时→42，24 小时→10 |
| 主动性 0.20 | 对方开启会话比例 0.5 · 连发率 0.2 · 提问率 0.3 | 开启 20%→35，50%→65，70%→82 |
| 投入度 0.20 | 对方字数占比 0.4 · 长度比 0.3 · 媒体占比 0.1 · 短回复率 0.2（反向） | 字数占 30%→40，55%→72，70%→85 |
| 情感温度 0.20 | 关心词率 0.45 · 笑率 0.25 · 亲昵词率 0.30 | 关心率 3%→50，8%→68，15%→82 |
| 未来指向 0.15 | 提议率 0.35 · 接受率 0.30 · 改期率 0.15（反向）· 落定率 0.20；材料里没有任何提议时退回未来词率 | 接受率 40%→50，60%→70，80%→88 |

**总分** = 五维按权重加权。**AI 模式**下每维 = 规则分 × 0.5 + 模型分 × 0.5（模型分来自综合阶段的 `dims`）。

置信度：回应性按样本数（≥15 高、≥5 中）；主动性按会话数（≥5 中）；投入度按对方文本数（≥30 中）；情感温度与未来指向**永远是低**，因为它们只靠词表。

## 第三步：阶段与边界

**阶段**（`scoring/stage.py`）按优先级：用户手动确认 → 出现「在一起吧 / 男朋友 / 官宣」→ **确定关系**；冲突词（烦死了 / 随便你）与道歉词（对不起 / 我的错）同现 → **修复期**；对方文本 <10 → 未知；关心+亲昵率 ≥6% 或未来词率 ≥8% 或有亲昵词 → **暧昧**；≥3 段会话或 ≥30 条文本 → **初识**；否则 **初步接触**。「稳定」还要求 ≥8 段会话且跨度 ≥21 天。

**边界**（`scoring/boundary.py`）：只看材料**末尾 30 天**：命中安全词（报警 / 自残…）→ 安全信号；停止联系词（别再联系我 / 拉黑 / 我有对象了）→ 停止联系；拒绝词且无改期词 → 明确拒绝。更早的命中写进说明、不作当前状态。

## 第四步：不再有门禁（v0.8）

v0.7 及以前，对方文本 <20 条、独立会话 <2、覆盖度 <0.6、停止联系或安全信号，都会让总分不显示；语义里的负向判断也需要 ≥2 个独立片段才显示。**v0.8 起全部取消**：总分永远给出，这些情况变成分数旁的「注意」提示（`caveats`）和置信度降级；边界信号变成报告顶部的醒目横幅，附证据，不改任何数字。唯一保留的过滤是攻略里的操控话术（让对方吃醋 / 故意不回），它不是评分门禁，是不给有害建议。

## 诚实边界

- 锚点、权重、词表是 2026-09 写下的产品假设，没有任何盲测校准。真实材料上的规则总分落在 53–65（9 段），只说明它们对同一个人的材料是稳定的，不说明它们对。
- 情感温度只靠词表：一句「早点休息」和一句「早点睡别烦我」命中同一个词。
- 邀约链靠词表识别提议与答应，口语化的邀约（「走？」）识别不到。
- 这些数字不预测关系结果。要知道方向对不对，只有两周后的回访（`docs/EVAL.md` 阶段 6）。
