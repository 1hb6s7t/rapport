# 双人裁定工作区

1. 把 `reviewer_A.csv` 与 `reviewer_B.csv` 分别交给两名评审，**互相看不到对方**。
2. 每行在 `pragmatic_tags` / `emotions` 里填写标签，多个用 `|` 分隔；
   语用标签只能取自：信息确认、反讽、委婉拒绝、寻求安慰、撒娇假生气、真生气、调侃
   情绪只能取自：不满、亲近、伤心、开心、担忧、混合
3. 不确定就留空，**不要猜**：留空会记为弃答，这是合法的判断。
4. 认为金标签本身有争议的，在 `notes` 里写明理由——争议条目必须保留，不允许删题。

两张表都不显示项目作者的原标签，避免锚定效应。
