## 中文私有数据对照：实际完成 24 次

数据快照 `793cfff237444b898e07eab7e2fa8f61`，全部本地解密读取，源 `D:\.rapport` 不修改、不上传。固定哈希抽样 1200 条训练、200 条验证、400 条测试；来源组划分沿用快照。每个方法分别比较共享上下文网络+多任务头、两个独立上下文网络+任务头。两者均复用同一冻结中文编码器，**不是两个完整中文编码器端到端微调的比较**。

- 3 个固定 seed：20260922、20260923、20260924；每配置 3 轮，AdamW，hidden=64，batch=16。
- 保留情绪及意图的全部多标签真值，BCEWithLogitsLoss；类别权重仅从训练集计算，不取首标签。
- 仅在验证集选 checkpoint 与每任务阈值，测试集不参与选择。测试中训练未见标签计为漏检。
- 所有模型看到同一目标之前最多 7 条+目标。离线标签可能参考过后文，**因果输入不使后见标签自动变成人工因果金标准**。
- 未把标注者挑出的证据追加到模型输入，以避免用答案指导上下文选择。
- 测试只有 2 个独立来源组，属于开发实验，不能解释为公众或跨用户准确率。

综合 macro-F1 为情绪与意图 macro-F1 的均值（0–1，越高越好）：

| 方法 | 共享：均值 ± seed 标准差 | 分任务：均值 ± seed 标准差 |
|---|---:|---:|
| 当前句 MLP | 0.1517 ± 0.0030 | 0.1537 ± 0.0019 |
| DAG-ERC 中文适配 | **0.1855 ± 0.0113** | **0.1894 ± 0.0125** |
| DialogueGCN 公式适配 | 0.1469 ± 0.0016 | 0.1527 ± 0.0045 |
| DialogueCRN 中文适配 | 0.1421 ± 0.0066 | 0.1460 ± 0.0128 |

DAG-ERC 在这轮预算和数据下表现较好；共享与分任务差约 0.40 个百分点，小于本轮 seed 波动。共享 DAG 上下文+任务头约 67.8 万参数，分任务约 134.1 万；这提供下一轮优先验证共享方案的依据，**不是启用生产的通过证明**。整体成绩偏低、少数类不稳定，不替换现有分析器。

这组实验与先前 Naive Bayes 使用的训练数量、评测子集和多标签计分方式不同，不能直接拿两张表宣布提升比例。也不把这些分数换算为“喜欢程度”。

## 综合小语言模型对照

`research_llm_baseline.py` 使用明确指定的本地 HF 模型，并通过现有 `scripts/intent_eval.evaluate_case` 调用原 `build_intent_input → run_intent → validate_intent` 路径。保留现行提示、参考例、证据和标签校验；v0.8 的旧负面标签抑制已取消，不额外恢复旧门槛。同时记录格式失败，失败样本不被静默删掉。

本机模型与原云 API 型号不相同，因此标记为“现有提示 + 本地小模型”对照，不能标记成生产云模型的原成绩。若使用 32 条 pilot，会从神经模型已保存的测试预测中**重算相同 32 个 ID**，不与 400 条汇总排名直接比较。原始响应和错误案例仅加密保存。

公开基座 Qwen3-0.6B，使用现有意图提示和校验流程、贪心生成、最多 384 个输出 token。没有为这次情绪/意图任务微调该小 LM；它与使用 1200 条监督样本的任务头训练条件不同，不能据此断言综合 LM 架构总体较差。

## 概率校准与拒判：已完成独立对照

对 DAG-ERC 共享/分任务各 3 seed 的既有权重做校准，没有重训或按测试集调整温度。参考 [Guo et al., ICML 2017](https://proceedings.mlr.press/v70/guo17a.html) 的温度缩放思路，本项目明确采用**多标签 sigmoid 适配**：每任务一个正标量 T，在验证集 200 条上最小化未加类别权重的 binary NLL；确定 T 后只在独立测试 400 条计算指标。T 搜索范围固定 0.1–10，实测为约 0.398–0.616。原分类阈值没有因此被重新选择。

下表为三个 seed 的均值，ECE/Brier 越低越好；仅针对模型已有标签概率，不包含“创造未见类别能力”：

| 模型 / 任务 | ECE 原始 → 校准 | Brier 原始 → 校准 |
|---|---:|---:|
| 共享 / 情绪 | 0.11164 → 0.02239 | 0.07385 → 0.05880 |
| 共享 / 意图 | 0.11456 → 0.02475 | 0.07326 → 0.05728 |
| 分任务 / 情绪 | 0.11280 → 0.01959 | 0.07455 → 0.05891 |
| 分任务 / 意图 | 0.11273 → 0.02391 | 0.07214 → 0.05714 |

每个最终运行目录的 `calibration.json` 包含原/校准 NLL、逐箱可靠性统计、标签平均 ECE，以及固定阈值 0/0.5/0.6/0.7/0.8/0.9/0.95 的覆盖率与错误率。详细概率数组位于加密 `*.calibration.bin`。

拒判曲线使用“最高概率标签是否属于真实标签集合”的错误率，**不是整组多标签全部正确率**。共享模型校准后在固定阈值 0.8 下，情绪平均覆盖率只有 10.42%、被接受样本 top-1 错误约 13.60%；意图覆盖率仅 5.17%、被接受错误约 14.52%。阈值 0.9 的支持样本极少，不能因观测到零错误就称可靠。这些开发标注上的概率改善不等同稳定的中文人群校准，校准器和拒判阈值均未启用到产品。

## 互动标记与离线变化点的补充实验

已复用 ConvoKit 的中文 CSCW 标记提取器及词表，固定提交 `5dabba5ae034686185d9ff6612e2d57d694bff68`，保留 MIT 许可证和上游文件哈希。本地适配只改导入/资源路径与 UTF-8 解码，并用 jieba 0.42.1 提供中文分词；这和作者示例的 spaCy 分词不同，不继承论文成绩。得到的是感谢、道歉、礼貌请求等可观察的措辞标记，不用于计算喜欢程度。

趋势部分实际运行 ruptures 1.1.10 的 PELT（l2/rbf 两种代价，各 2/4/8/12 四种预设惩罚），输入为完整会话段的消息方向占比、轮次切换、文本长度、相邻轮次间隔和文本占比，按中位数/四分位距归一化。消息类型为媒体也保留已知方向及可靠时间，未知时间不补造。少于八个可用会话段时不判断；不同参数共同检出的位置只是参数敏感性摘要，不是正确概率。

已在当前全部 9 个匿名来源运行：56,173 条具可靠时间的双方消息用于会话统计，45,562 条文本用于措辞标记，形成 1,348 个符合条件的双方会话段。产物位于应用目录 `research/interaction/00102dd954744d39a1d136f6d5089a55`；公开 `summary.json` 仅含统计，`evidence.bin` 加密保留消息索引与会话证据。工作台显示对应独立研究卡，不进入生产评分。没有人工变化点真值，不能说比原趋势规则更准确；PELT 看完整历史，只可解释为离线复盘。

三个专项验证通过：未知时间不被计入、原作者中文标记提取可用、已知合成阶跃的变化点能被定位且不把序列终点当作变化。运行方式：安装后端可选依赖 `research-signals`，执行 `python -m rapport.research.interactions --data-dir <应用目录> --dataset-id <快照ID>`。

## 运行、取消与清除（通用研究任务）

代码入口：

```powershell
# 设置到具有 torch/transformers 的独立训练环境；不把训练依赖装进 OCR 环境。
$env:PYTHONPATH = 'D:/work/rapport/backend'
$env:HF_HUB_OFFLINE = '1'
python -m rapport.research.runner --data-dir <应用目录> --dataset-id <快照ID> --encoder <本地BGE目录> --device cpu
python -m rapport.research.summarize --data-dir <应用目录> --minimum-seeds 3
python -m rapport.research.llm_baseline --data-dir <应用目录> --run-id <完整运行ID> --model <本地HF模型> --device cuda --limit 32
python -m rapport.research.calibration --data-dir <应用目录> --run-ids <三个完整运行ID，以逗号分隔>
python -m rapport.research.public_run --data-dir <应用目录> --source <官方MELD_Dyadic目录> --encoder <本地BGE目录>
```

目录：`<应用目录>/research/runs/<run_id>/report.json`，加密 `*.weights.bin`、`*.predictions.bin`；向量在 `research/feature_cache/*.bin`。公开摘要应使用白名单，不向界面原样返回 config 的本地路径。模型不自动登记为可启用生产版本。

`ResearchRun` 登记 PID 与代际号，各编码/训练批次和保存前检查取消及快照是否仍存在。`safe_wipe(data_dir)` 先锁定代际并拒绝新任务；旧任务仍活跃时返回 `research_stopping`，等待退出后重试清除。清除过程持控制写锁，验证目录边界并拒绝 symlink/junction；不杀其他进程。清除后旧进程无法重新写回。已退出但未完成的任务由 `reconcile_reports()` 标为 interrupted。

实际专项：在独立 Torch 环境中已运行 27 项测试，覆盖 8 种网络前向/反向、多标签、因果图、分区及去重、原生 CRN 分组算子、许可携带、取消与清除屏障、公开数据适配、现有提示验证路径、none/不确定/弃判的区别，以及温度与固定拒判阈值。无 Torch 的主服务环境跳过依赖项，不报告为神经测试已执行。
