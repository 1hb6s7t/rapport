# 语用/情绪词表 v2 提案（**已在 v0.7 实施**，2026-09-19）

> 依据：`docs/LABEL-MAP.md` 2026-09-18 的映射结果。v1 真实基线（`docs/EVAL.md` §15.3–15.5）跑完后于 v0.7 实施。实施结果：`docs/label_map_v2.json` 重新映射后，语用「无类」26.7% → **4.6%**，情绪 64.3% → **1.4%**；合成题金标签按 v2 补标 31 条（`同意接受` 16、`分享陈述` 9、`询问` 2、`观点评价` 1，`信息确认` 35 → 7）。v1 与 v2 数字不可比。

## 1. 数据说了什么

| 事实 | 数 |
|---|---:|
| 对方消息里固定语用词表**没有类**的（只落到 none） | 26.7% |
| 对方消息里固定情绪词表没有类的 | 64.3% |
| 落到 none 的前五个开放标签 | 观点评价 922 · 表达感受 789 · 抱怨 575 · 笑声回应 506 · 同意接受 401 |
| 落到 none 的情绪前四 | 无明显情绪 14,646 · 无奈 1,999 · 惊讶 811 · 困惑 623 |
| 映射后真正落到风险类的 | 真生气 102 · 反讽 54 · 撒娇假生气 21（合计 <0.7%） |

v1 词表是按"抓风险与暧昧信号"设计的：8 个语用标签里 5 个是负向或暧昧，日常聊天的绝大多数（分享、评价、抱怨、同意、笑）只能落到"信息确认"或没有类。**这意味着真实材料上的 macro-F1 主要由极少数风险类决定，而它们的支持数只有几十条**；数字会很不稳定，且不反映用户看到的绝大多数判断是否合理。

## 2. 提案

**语用（v1 8 → v2 13）**：保留 8 个，新增 5 个中性类，让"多数消息有类"。

| 新标签 | 吸收的开放标签（映射表 v2 要改） | 为什么是独立类 |
|---|---|---|
| 分享陈述 | 陈述信息、分享资料、回顾/讲述经历、报告状态/进展 | 目前全塞进"信息确认"，把"确认"这个语用功能稀释掉了 |
| 询问 | 询问信息/原因/安排/位置、请求澄清、征求意见 | 提问是主动性的直接信号，好感度 initiative 维已经在数它，语义层却没有类 |
| 观点评价 | 观点评价、正面/负面评价、赞许、赞赏、比较评价 | 922 次，v1 没有 |
| 抱怨 | 抱怨、表达不满、表达无奈（对第三方/事） | 与"真生气"（对我方）必须分开：抱怨工作不是对用户生气，这是负向门槛误伤的一个来源 |
| 同意接受 | 同意接受、回应认同、回应确认、给予许可 | 与"委婉拒绝"成对，邀约链的 accept 已在规则层，语义层缺对应类 |

**情绪（v1 7 → v2 10）**：新增 `无明显情绪`、`无奈`、`惊讶/困惑`。`无明显情绪` 是 51% 的真实答案，没有它模型只能在"不确定"和硬猜之间选，这正是 0.70 弃答率的一部分来源。

**负向集合不变**：`NEGATIVE_PRAGMATIC = {真生气, 反讽, 委婉拒绝}`，`NEGATIVE_EMOTIONS = {不满, 伤心}`。新增类全部中性，不进门槛。

## 3. 改动面（v0.7 实施清单）

| 文件 | 改什么 |
|---|---|
| `schemas/report_v1.py` | `PRAGMATIC_TAGS` / `EMOTIONS` 扩展；`NEGATIVE_*` 不动；报告体不升版本（新增枚举值向后兼容，旧报告读取不受影响） |
| `llm/prompts/intent.md` | 标签取值两行；每个新类一句判据。改动会自动进 `PROMPTS_VERSION` 哈希 → 快照断线，这是预期 |
| `llm/intent.py` | `_clean_tag_entries` 用的是常量，不用改；门槛逻辑不动 |
| `scripts/intent_eval.py` | `G` 字典加 5 键；**120 条合成题的金标签要按 v2 补标**（现在的"信息确认"里一部分该拆到分享/询问/同意）——这是最大的人工成本，约 2 小时 |
| `docs/label_map_v1.json` → `label_map_v2.json` | 上表的开放标签改指向新类；`none` 占比预期从 26.7% 降到 <8% |
| `frontend/src/components/Intent.tsx` | `ALL_PRAGMATIC` 列表；新类文案与色调（中性灰） |
| `docs/ANNOTATION-PROMPT.md` | 提示词 A 的词表段 |
| `docs/EVAL.md` | 写明 v1/v2 数字不可比，v2 基线从零建 |

## 4. 验收

- 映射后 `none` 占比 <8%（语用）、<15%（情绪）。
- v2 合成题 120 条 `--repeat 3` 与 v1 同模型对照：新类 F1 ≥0.6（它们本该容易），风险类 F1 不低于 v1 区间下沿。
- 真实材料 300 条抽样：弃答率从 0.70 显著下降（≥0.15），极性错误率 ≤5%。

## 5. 不做什么

- 不把 3,867 个开放标签本身变成产品词表：那是描述用词表，不是分类法。
- 不动情绪的负向集合，不因为"无明显情绪"多而放宽负向门槛——门槛的问题在 C4 单独诊断。
