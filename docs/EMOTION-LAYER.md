# 离线情绪研究层（规则模式）

> 状态：**默认关闭**。开关在「设置 → 分析与个性化 → 离线分析层（规则模式）」。
> 全部在本机运行，不联网、不计费、**不进入客观关系分数**。

规则模式的「逐句语义与情绪」默认引擎是单句小模型。开启本层后，改由多个本地信号融合判断，
每条读数都带各信号的投票与最相似例句的标签（不带例句文本），可追溯、可反驳。

## 融合规则

全部可见于输出，不藏在数字里：

1. 链接 / 邮箱 / 代码编号 / 纯英文长句 / 过短文本 → 直接「无明显情绪」，并写明理由。
2. 三个信号按权重混合；最高分 < 0.35 → 「无明显情绪」，次高两个标签保留为候选。
3. 最高分是负面（不满 / 伤心）时，三个信号至少两个同意才成立，否则降为「不确定」并附提醒。
4. 最高与次高相差 < 0.05 → 「不确定」，两者都列为候选。
5. 每条读数带 `method_votes`（各信号投票）、`similar_examples`（最相似例句的**标签与相似度**，不带文本）、
   `source="grounded"`、`post_hoc=false / context_mode=reply`。

权重与阈值都在数据集的 **validation** 切分上选定，test 只跑一次。

## 评测

标签分两套：数据集的 **AI 辅助弱标注**（约 10,821 条 test、630 条 validation），以及 **400 条独立参考标注**
（由 Claude 逐条判读，与弱标注生成者、与待评模型都独立；性质是强模型参考标注，**不是人工金标**）。

| 方法 | macro-F1（参考 400） | accuracy（参考 400） | macro-F1（弱标注 test） | accuracy（弱标注 test） |
| --- | --- | --- | --- | --- |
| 多数类（无明显情绪） | 0.078 | 0.640 | 0.075 | 0.601 |
| 单句 StructBERT（标定后） | 0.076 | 0.140 | 0.056 | 0.092 |
| 仅 kNN | 0.189 | 0.303 | 0.179 | 0.329 |
| **融合层** | **0.276** | **0.618** | 0.202 | 0.594 |

两套标签上的数字接近，说明弱标注对照没有被系统性抬高。逐类看，融合层能读「开心」与「无明显情绪」，
负面与细微情绪基本读不出——这正是负面标签要「两个信号同意」并附提醒的原因。

### 伤心类的类别先验修正

最初融合层在 26 条伤心上 F1 = 0。诊断：锚点语料类别极不平衡（`per_label` 上限 300，但 train 切分里
伤心只有 21 条可用锚点，而常见类各 300 条），`knn_scores` 按相似度³加权求和后直接归一化，
少数类被多数类淹没。修正：把每个类别的相似度质量除以 `count ** PRIOR_ALPHA` 再归一化
（`anchors.PRIOR_ALPHA = 1.0`，即完全类别均衡；`0.0` 就是原行为）。参数只在 validation 上选：

| PRIOR_ALPHA | validation macro | validation 伤心 F1 | 参考 macro | 参考 伤心 F1 |
| --- | --- | --- | --- | --- |
| 0.0（原） | 0.2395 | 0.000 | 0.2213 | 0.000 |
| 0.7 | 0.2721 | 0.348 | 0.2611 | 0.235 |
| **1.0（采用）** | 0.2576 | 0.270 | **0.2759** | **0.436** |

选 1.0 而非参考列更好的 0.9：validation 上 0.7 与 1.0 的差在噪声内，故取理论值「完全均衡」。
修正**同时**改善两套标签（都从 0 起跳），不是拟合某一套读法。自助法（4000 次）macro 差区间
[0.023, 0.086]、伤心 F1 差 [0.255, 0.592]，都不跨零；accuracy 差跨零。

## 公开数据全量调参：结论是调不动

在 **EWECT**（SMP2020 微博情绪评测官方数据，人工标注，27,768 train / 2,000 dev / 5,000 test，6 类）
上重建同一条融合管线，dev 上随机搜索 3,000 组 + 坐标细化，搜 9 个参数：

| 集合 | 配置 | macro-F1 | accuracy |
| --- | --- | --- | --- |
| EWECT test | 生产参数 | 0.4956 | 0.5382 |
| EWECT test | EWECT 调优后 | **0.6189** | 0.6124 |
| 真实数据参考 400 | 生产参数 | **0.2781** | 0.6050 |
| 真实数据参考 400 | EWECT 最优 | 0.2346 | 0.3925 |

微博上 +0.12，但**完全不能迁移**（自助法 macro 差 −0.0435 [−0.082, −0.003]，accuracy 差 −0.2125，
显著更差）。根因是参数与领域强耦合：EWECT 中性仅约 20% 而真实聊天 64%（阈值本质由类别先验决定）；
EWECT 锚点完全均衡而生产锚点是 21/136/158/300 的偏斜分布；最优信号方向相反
（EWECT 上质心最好，真实数据上 kNN 最好）；语域不同（微博公开帖 vs 微信私聊）。

改在真实数据上调同样没有显著收益（validation 搜 3,000 组取最优，参考集 macro 差 +0.0193
[−0.018, +0.057] 不显著，accuracy 显著更差）。**结论：剩下的误差不是超参数问题。**

## 现成本地大模型对照与门控方案

用本地已有的 Qwen3 指令模型零样本提示分类，在同一 400 条参考标注上评测：

| 方法 | accuracy | macro-F1 | 伤心 F1 |
| --- | --- | --- | --- |
| 融合层 | 0.6050 | 0.2781 | 0.441 |
| Qwen3-8B 零样本（加中性先验） | 0.6850 | **0.3183** | **0.632** |

8B 略好，但优势几乎全部集中在伤心一类（融合层原来一条未中，先验修正后到 0.436，8B 是 0.632），
其余类别两者接近；且每条消息都要一次本地推理。融合层反而在**中性**上更准（它判「无明显情绪」的
259 条里对了 74%，8B 只有 68%）。于是试**门控**：融合层判中性就保留它，判有情绪才调用 8B。

| 方法 | macro-F1 | accuracy | 伤心 F1 | 8B 调用量 |
| --- | --- | --- | --- | --- |
| 仅融合层 | 0.2781 | 0.6050 | 0.441 | 0 |
| 仅 8B | 0.3183 | 0.6850 | 0.632 | 400 |
| **门控** | 0.2877 | **0.7275** | 0.632 | **141（35%）** |

门控在 accuracy 上同时超过两者（对融合层 +0.1225 [+0.0825, +0.1650]，p < 0.0001；
对仅 8B +0.0425 [+0.0150, +0.0700]，p = 0.001），两个方向的 macro 差都跨零。
诚实的说法是「macro 持平、accuracy 更好、8B 调用少 65%」，不是「超过 8B」。
门控方向在同一 400 条上选定，两个 bucket 的 accuracy 是样本内数字。

**注意**：参考标注由大模型独立完成，8B 也是大模型，两者同源，8B 的一部分优势可能来自
「与标注者风格一致」而非真的更准。要坐实需要人工金标。逐样本数据与脚本见 `output/` 与 `tools/`。

## 诚实边界

- 融合层 macro-F1 约 0.28，**只能作候选信号，不能单独定情绪**；accuracy 与多数类基线接近。
- 它能读「开心」与「无明显情绪」；负面（不满 / 伤心 / 担忧）与细微情绪基本读不出，负面一律附提醒。
- 参考标注是强模型独立标注，不是人工金标；上下文头复训对照显示在弱标注上无可测量增益，
  因此**不接入**上下文建模。
- 更小的类（亲近、混合、不确定）锚点太少，同样的先验修正覆盖不到。

## 重建

```bash
# BGE 编码器：导出（训练 venv，有 torch）→ 校验并写 manifest（后端 venv，有 onnxruntime）
python tools/bge_model.py export --source <bge 权重目录> --out models/bge-small-zh-v1.5
python tools/bge_model.py verify --dir models/bge-small-zh-v1.5 --source <bge 权重目录>

# 近邻语料库（加密写入 <data-dir>/grounded/anchors.bin）、温度标定、评测
python tools/build_anchors.py --data-dir <data-dir> --dataset-id <已构建数据集 id> --per-label 300
python tools/fit_calibration.py --data-dir <data-dir> --dataset-id <id>
python tools/evaluate_grounded.py --data-dir <data-dir> --dataset-id <id> --split test --limit 0
```

研究脚本：`tools/experiment_sad_knn.py`（先验修正扫描）、`tools/sweep_public_fusion.py`（公开数据全量搜索）、
`tools/check_transfer.py`（把任意配置拿到真实锚点与真实标注上评）、`tools/evaluate_local_llm.py`（现成模型对照）、
`tools/experiment_gated_hybrid.py`（门控方案）、`tools/experiment_public_anchors.py`（补锚点实验）。

## 隐私与边界

- 近邻语料库是用户自己的消息，用应用密钥加密（fernet + zlib）落盘；报告里只出现最相似例句的
  **标签与相似度**，永远不带例句文本。
- 读数不进客观分数、不进画像假设；AI 分析模式不使用这一层。
- 一切组件缺失都只是降级：BGE 或语料库缺失 → 退回单句模型；全部缺失 → 规则模式与此功能出现前完全一致。
