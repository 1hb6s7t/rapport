## 使用时需要注意的实际约束

- **磁盘**：本机 C 盘仅剩约 18 GB，模型与数据目录应放在空间更大的盘（如 G 盘）。
- **端点兼容性**：部分网关按 `User-Agent` 拦截 OpenAI SDK 默认指纹（返回 403），本项目已自报 UA；另有网关会注入自己的系统提示，可能影响判断类任务的输出，评测时要记录。
- **价格**：预设里的价格是"核对于某日"的手工数值，供应商可能随时调整；未公开单价的端点界面会显示"未知"并要求显式确认。
