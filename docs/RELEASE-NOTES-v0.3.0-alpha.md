# 心迹 Rapport v0.3.0-alpha 发行说明

日期：2026-09-15。本地 tag：`v0.3.0-alpha`（**仅本地**：仓库尚无远程，版权署名待定）。

## 这个版本能做什么

- **导入**：A/B 粘贴、WhatsApp TXT、QQ 消息管理器 TXT、微信第三方导出 CSV/JSON、Telegram 单聊 JSON、
  message-v1 JSON、聊天截图（本地 RapidOCR）。不读取或解密任何平台数据库。
- **规则模式（零外发）**：五维行为指标（回应/主动/投入/温度/未来）、按天/周/月分桶的趋势、
  阶段与边界判断、通用行动骨架。
- **AI 模式（自带 Key）**：出网前预览脱敏正文、目的地与估价并逐次确认；带证据与反证的观察、
  沟通侧写与四轴推断、1–3 条带停止条件的行动、雷区与三种话术。
- **语义与情绪**：逐句多标签判断，允许"材料不足"；负面判断在独立证据不足 2 个片段时只作候选解释；
  前端默认折叠这类判断。
- **标签先验**：MBTI/星座/属相作为可推翻的初始假设，权重随已确认证据衰减，**永不进入好感度分数**。
- **日记与代回复**：日记只在本机、可逐条开关并限定可用关系；话术草案带防编造校验；
  严格模式只用你逐字批准过的短句；**不代发任何消息**。
- **历史**：真实快照（同材料同版本只出一点）、阶段变化与画像版本都可回看，且不确定的地方会写"为什么变了"。
- **删除**：删导入清加密原文、删报告清正文+快照+画像版本、清空数据清所有派生存储；都有测试。

## 实测数字（必须一起读）

| 项目 | 结果 |
|---|---|
| 后端测试 | 238 项通过；前端 tsc / vitest / 构建通过 |
| 语义情绪 macro-F1（60 组、context、3 轮） | **0.559**，区间 0.542–0.575 |
| 无参考例 | 0.426 |
| 只有单句时 | 几乎全部弃答 |
| 依赖审计 | pip-audit 无已知漏洞 |

**噪声区间 0.033**：改动小于约 0.03 的 macro-F1 在当前设置下测不出来，因此本版本不宣称任何"识别准确率"。

## 为什么是 alpha 而不是 beta

四个门槛都没过：① 语义准确率未达 0.70；② 评测金标签仍是单人编写（双人裁定工具已就绪，未执行）；
③ 没有用户实验（方案里的 G1/G3 未做）；④ Linux/macOS/Docker、真实截图版式、性能指标都未验证。

## 这个版本明确不做

- **本地模型（Ollama/Qwen）与断网验收**：按 2026-09-15 的决定跳过。因此"本地优先"目前体现为
  **默认只用回环端点、不静默调用云**，而不是"离线可用"。
- 不做商业化、账户、支付、云同步、社区、遥测；不训练模型；不做人格诊断或危机干预；
  不自动发送任何消息；不抓取或解密任何平台数据库。

## 使用前请知悉

- 好感度指数是**行为描述指数，不是概率**，不预测关系结果。对方明确拒绝时总分会被抑制。
- 语义情绪判断会出错，尤其容易把中性回应误读成"冷淡"——这也是负面判断默认收起的原因。
- 请勿把真实聊天粘进公开 Issue；仓库模板要求用合成样例复现。
