## 发布时可以说什么

- 可以：本地运行、零外发模式、证据可点开、删除级联可验证、五个维度与趋势是按公开规则计算的、标签不进入分数。
- 不可以：识别准确率、预测准确率、挽回成功率、稳定人格诊断，也不可以把 238 项测试当作产品效果证明。
