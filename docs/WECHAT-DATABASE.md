# 微信数据库读取（可选组件）

> 状态：**默认关闭、按需开启**。全部在本机运行，不上传、不联网。
> 平台：Windows。需要本机已登录的微信客户端。

规则模式与 AI 模式都不需要这个组件。它存在的意义只有一个：把本机微信里**你自己的**聊天记录
结构化地读出来，交给后续的校对、分析、归档流程，省去手动导出和截图 OCR。

## 它做什么

- **结构化历史读取**：选择本机账号与好友，读取最近 10–5000 条消息。不需要滚动微信窗口。
  逐条保留时间、文字、引用、图片、语音、视频、表情、文件、链接、小程序与转账卡片。
- **增量同步**：手动同步，或在页面打开时轮询新增。账号、好友与关系对象共同限定范围；
  关闭页面即停止，重新打开可恢复本浏览器保存的读取记录。
- **加密断点**：消息与每个分片的复合游标一起原子加密保存。保存失败不推进游标；
  相同 `sort_seq`、不同分片或 `local_id` 的消息不会被简单去重丢掉。
- **语音转文字（可选）**：读取时可把语音转成文字，用本机 SenseVoiceSmall INT8 在 CPU 上识别，
  正文加 `[语音转文字]` 标记。转写不调用任何云端或聊天模型。
- **回复窗口绑定**：把数据库材料与刚核对的可见窗口上下文绑定，然后沿用既有的校对、预览、
  单次执行与回执流程。

## 它不做什么

- **不发送任何消息**。没有自动回复、没有群发、没有按下 Enter 即记成功。写入路径仍需逐条人工点击。
- **不注入、不 Hook 微信客户端**，不加载上游的 GUI 进程内存写入模块。
- **不下载媒体附件**：图片、语音、文件、视频只保留类型与占位。
- 不启用群聊读取、定时发送、外部工具执行。

## 工作原理

- 首次连接时，从本机**已登录的微信进程**只读取得所选账号的数据库密钥，经数据库页校验。
  不修改微信进程，不切换账号。
- 连接期间在私有工作目录建立只读查询所需的临时明文 SQLite 副本；断开数据库读取或正常关闭应用会
  删除该副本。突然断电或强制结束可能留下工作目录，需要清理后重新连接。
- 密钥、同步状态与应用材料用应用自己的 Crypto 加密，位于数据目录下的 `wechat-dsh/` 与加密 blob 存储。
- 数据库引擎可能回退到旧副本；适配层检查主库 / WAL 的时间、大小与合并状态，已知过时的副本不推进游标。
- 本机 `contact.db` 同时包含好友与非好友群成员，同名昵称不能直接取第一条：搜索先限制到当前版本的
  有效私聊好友，再要求完整名称唯一匹配；未知的好友表结构会拒绝该路径。
- 消息分片有自己的 `Name2Id` 映射，不同分片的相同编号可能表示不同人，因此不使用全局映射，
  也不假定编号 2 就是自己。稳定消息 ID 包含账号与会话，优先 `server_id`，缺失时用分片加 `local_id`。

## 存储与生命周期

- 固定所选账号，不自动切换。删除关系对象会撤销该关系的同步结果。
- 断开数据库读取保留已导入材料与加密同步状态，便于再次连接。
- 同步窗口最多保留最近 5000 条；更早的材料通过已导入材料与归档保留。轮询只跟踪新增记录，
  不宣称能侦测微信对旧记录的任意就地修改。

## 隐私、法律与合规（请务必阅读）

- 本组件读取的是**本机上已登录账号的本地数据库**。请只在你自己的设备、你自己的账号上使用。
- 逆向解析本地数据库格式与读取进程内存中的密钥，**可能违反微信 / 腾讯的服务条款**。
  是否使用、在什么范围内使用，由使用者自行判断并承担相应后果。
- 读取到的内容属于高度私密材料。本项目默认只在本机保存，出网前仍需脱敏与逐条确认；
  请不要把它用在未经同意的第三方身上。
- 若你所在地区对这类工具有额外限制，请遵守当地法律。

## 安装与启用

```bash
cd backend
uv sync --extra wechat-database --extra desktop   # desktop 提供 Windows UI Automation 依赖
uv run rapport serve
```

在「设置 → 微信聊天读取」里启用，选择账号与好友后读取。原生语音组件（WeFlow WCDB 桥）见
[`native/weflow_wcdb/README.md`](../native/weflow_wcdb/README.md)，它是可选构建项，不构建时语音转文字不可用，
其余功能不受影响。

## 代码位置

- `backend/rapport/desktop/dsh_database.py` — 固定账号、加密密钥、WCDB 读取、分片发送者映射与游标
- `backend/rapport/desktop/dsh_source.py` — 消息源适配与 message-v1 转换、加密批次保存
- `backend/rapport/desktop/dsh_worker.py` — 单线程桌面工作线程，原文、不自动重试
- `backend/rapport/api/wechat_dsh.py` — 已配对会话下的配置、账号、读取任务、导入与绑定 API
- `frontend/src/components/DshReader.tsx` — 数据库读取入口
- `backend/rapport/vendor/wechatauto_db` — 数据库引擎
