## 组件与素材

- `components/brand/Brand.tsx`：品牌图标、原图字标、透明显示滤镜与生肖/星座图集。
- `components/brand/WatercolorOrbit.tsx`：双向旋转星轨，支持暂停、速度、纯净星图和图案详情；紧凑模式用于数据工作区。
- `components/brand/BrandLanding.tsx`：未配对首页，接入真实配对和既有演示报告入口。
- `components/brand/PetalEffects.tsx`：单一鼠标监听和按需动画循环；路由卸载清理；表单输入区不散落花瓣。
- `components/ui/primitives.tsx`：共享原语。Modal 保持原有调用接口，采用原生 dialog 处理焦点、Escape 和背景阻隔，新增可选左侧抽屉显示。
- 图片统一放在 `frontend/public/atelier/`。Logo、十二生肖与十二星座为用户确认过的原始素材。人物、山水、纸张、桃花瓣沿用已确认网站素材。

## 视觉与交互规则

1. 品牌首页可以使用人物与大星轨；导入、校正、报告、日记等工作区采用纸张底色、粉紫晕染、淡山水三个背景层次。山水在卡片间隙和边缘显露，数据卡片保持接近不透明的浅色底。欢迎卡片右侧使用更清晰的山水，文字一侧覆柔和纸白渐变，保证内容阅读。移动端降低山水强度。
2. 官网导航下滑收起，上滑恢复；工作区保留既有侧栏与当前对象上下文。移动端导航使用可键盘操作的抽屉。
3. 真实分数、置信度、证据、边界提示和费用信息不因样式变化被隐藏、虚构或改写。
4. 鼠标动画使用局部变量与 ref，避免移动鼠标时导致整页 React 重渲染；页面隐藏时停止，触摸设备和减少动态效果设置下自动简化。
5. 卡片、输入、按钮、状态色、弹窗和图表沿用共享标准；所有交互保留可见键盘焦点。
6. 前端构建检查可使用 `npm run build -- --outDir dist`，产物只写入前端自己的 dist，避免覆盖迁移前已经存在的后端静态资源。
